The model: if you keep applying

This is a model, not a count. It assumes each year is a fresh try with the same chance, whatever happened before. The data cannot check this. People differ, so those still applying after several tries probably have lower chances. The real numbers are probably lower than these: read them as a best case.

Range: 95% interval from the year-to-year spread in the rate (2021 to 2025, each year counted as one data point). It covers how much the rate moves between years. It does not cover the risk that the "fresh try" assumption is wrong.

Source: DClinPsy Clearing House equal-opportunities data, 2021 to 2025 (contextual questions: 2023 to 2025). One trait at a time. Years where the source hid a count are left out, never counted as zero. Uses the explorer's data file and stats code (site/data/counts.json, site/js/stats.js).
